# Registros de decisões arquiteturais

Use ADRs para decisões duráveis com alternativas e consequências relevantes.
Não use ADR para cada refactor ou tarefa cotidiana.

```text
docs/adr/0001-titulo-curto.md
```

- Proposto
- Aceito

- Rejeitado
